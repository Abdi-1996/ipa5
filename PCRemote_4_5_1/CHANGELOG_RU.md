# PC Remote 4.5.1

- Вход по одному пользовательскому паролю вместо длинного Device ID.
- Пароль задаётся прямо в PC Remote Server; на диске хранится только salted PBKDF2 verifier.
- Смена пароля автоматически отзывает старые сессии.
- Настройки LAN / Tailscale / Auto доступны прямо на экране входа до авторизации.
- Можно указать LAN IP, Tailscale IP/MagicDNS и порт до входа.
- Обмен файлами ПК ↔ iPhone: загрузка файлов с iPhone в выбранную папку ПК.
- Для файлов с ПК добавлены «Сохранить в Файлы» и системное меню «Поделиться».
- В просмотре файла доступны отдельные кнопки сохранения и Share Sheet.
- Сохранены исправления ATS, Tailscale и Node Editor из 4.4.1.
